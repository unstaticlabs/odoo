# OCA add-ons workspace

This directory is populated by:

```bash
make oca-addons-sync
```

The repository tracks only this README. The actual OCA module directories are local symlinks to pinned checkouts under `oca-src/`, which is ignored by Git.

The pinned OCA modules provide Accounting reports, MIS statements, bank
statement foundations, reconciliation and other maintained Community
extensions used by the Distribution.
