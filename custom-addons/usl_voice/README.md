# Voice input

Focus an editable text field: a small microphone appears just above the insertion point, steps aside while you type and takes no room from the field. Select it, or press Alt+Shift+D, to dictate; the same keys end the dictation. The button shows in text fields and search boxes; in record pickers and number or date fields only the shortcut dictates. While you speak, a caption shows the last words heard: every two seconds or so Odoo sends the last twenty seconds for recognition, one request at a time. A dot follows your voice and a timer counts the recording. Select the red stop button to insert the transcript at the selection, or press Escape to cancel. Fields that close on an outside click, such as the kanban quick create or a new list line, stay open while you dictate. The recording is sent to the internal speech service and discarded after the request. If you switch fields or edit the destination, Odoo offers the transcript to copy.

In a record’s chatter, choose **Record a voice note** (the waveform icon; the microphone is for dictating text), speak for up to five minutes and select the red stop button to listen to the recording. The last thirty seconds count down. Send the message or log the internal note when ready. Recipients can play the recording while it is transcribed. A person with access can read its text under **Transcript** in the chatter or request the message’s `usl_voice_notes` field. The service receives audio only; the surrounding record and message are never sent.

The application sends MP3 audio to `POST /v1/audio/transcriptions` on the existing internal Ollama gateway. Odoo defaults to `http://ollama:11434`. Set `USL_VOICE_GATEWAY` on Odoo workers to use another internal gateway. The gateway owns worker selection, model readiness and speech recognition. A worker hears one recording at a time and answers 503 with `Retry-After` to the rest: Odoo then sends the recording again after the pause the worker asks for, for up to 20 seconds at the end of a dictation and 90 seconds for a voice note. Captions shown while speaking are not sent again, and neither is a 503 without `Retry-After` (a failed recognition, or no worker awake). Odoo sends the recording alone and reads the `language` the gateway heard; the gateway refuses any field other than `language`. When that is neither French nor English, Odoo sends the recording once more with `language` set to the speaker's own language if it is one of the two, French otherwise. After enabling the feature, check dictation in both French and English and send one voice note using an ordinary internal account. Voice notes require the existing OCA queue job runner.
