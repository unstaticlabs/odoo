# Voice input

Focus an editable text field and select the microphone to dictate. A dot follows your voice and a timer counts the recording. Select the red stop button to insert the transcript at the selection, or press Escape to cancel. Fields that close on an outside click, such as the kanban quick create or a new list line, stay open while you dictate. The recording is sent to the internal speech service and discarded after the request. If you switch fields or edit the destination, Odoo offers the transcript to copy.

In a record’s chatter, choose **Record a voice note**, speak for up to five minutes and select the red stop button to listen to the recording. The last thirty seconds count down. Send the message or log the internal note when ready. Recipients can play the recording while it is transcribed. A person with access can read its text under **Transcript** in the chatter or request the message’s `usl_voice_notes` field. The service receives audio only; the surrounding record and message are never sent.

The application sends MP3 audio to `POST /v1/audio/transcriptions` on the existing internal Ollama gateway. Odoo defaults to `http://ollama:11434`. Set `USL_VOICE_GATEWAY` on Odoo workers to use another internal gateway. The gateway owns worker selection, model readiness and speech recognition. After enabling the feature, check dictation in both French and English and send one voice note using an ordinary internal account. Voice notes require the existing OCA queue job runner.
