# Archive

Dated records and capture folders kept for history. Nothing here is updated,
and none of it is part of the served guide or the evergreen specifications.

- `accounting/`: past parity records and audits.
- `operations/`: incident and security reviews, one-shot action-risk reviews,
  QA fixtures and evidence folders.
- `product/`: readiness matrices, proposals, and the `qa/` and `screenshots/`
  capture folders of deliveries made before captures moved into pull requests.
- `qa/`: standalone capture folders.

Dated records that code or tooling still names, such as the action-risk reviews
and upstream-sync records quoted by the access-control policy, stay in their
original area.
