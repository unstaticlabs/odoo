# Why Some Items Still Require Accountant Review

Audience: CEO, accountant, finance operator.

The system can prove many technical facts automatically. It cannot make every accounting, legal or tax judgment by itself.

## Examples of Technical Evidence

Technical evidence can prove:

- debit equals credit;
- source and target move counts match;
- report rows export correctly;
- source report structure is imported;
- FEC structural validation passes;
- attachments are present;
- source and target tax records compare;
- source and target report line evidence compares.

## Examples of Professional Decisions

Professional review is still required for:

- accepting French report variants;
- accepting PCG 2024 treatment;
- accepting deliberate exclusion of association reports for a SASU;
- accepting tax-package values;
- accepting FEC readiness;
- deciding how to handle cross-boundary reconciliations;
- accepting a discrepancy with a known difference;
- closing Milestone 13.

## Why This Boundary Exists

Accounting software can preserve and calculate. It cannot replace professional responsibility.

For example, a FEC can pass structural validation and still require accountant review. A report can match technical controls and still require acceptance of classification, presentation and legal-form scope.

The review-decision workflow exists so these decisions are visible, durable and attributable.
