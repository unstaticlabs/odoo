# Prepare a French Declaration

1. Open **Declarations** and choose the obligation by deadline.
2. Read why the obligation applies, its fiscal period, rule version and deadline basis.
3. Select **Refresh from Ledger**.
4. Review prefilled fields. **View Entries** traces ledger-backed fields to accounts and journal items.
5. Resolve every **Needs Follow-up** item using the stated external source or company fact.
6. When validation is clear, select **Internal Review Ready**.
7. Select **Approve for Filing**, or request optional accountant review.
8. File externally in the tax portal.
9. Attach evidence or record the external reference, then select **Mark Filed Externally**.
10. Record payment, refund or carried credit and complete the obligation.

External values never silently replace ledger-derived values.
