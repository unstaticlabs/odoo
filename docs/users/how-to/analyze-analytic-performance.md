# Analyze Analytic Performance

1. Open **Accounting > Reporting > Analyse analytique**.
2. Confirm the active **Current Fiscal Year** and **Revenue and Spending**
   filters. Remove either chip when you need a different population.
3. Start with analytic activity in rows, month in columns and **Net
   Contribution** as the measure.
4. Select **Measures** to add Revenue, Spending, Accounting Amount or Count.
5. Select a row or column header to add another level, such as Project, Epic,
   financial account, account category, partner, product, journal, company,
   quarter or week.
6. Use **Flip axis** or **Expand all** to change how the same population is
   presented.
7. Select a value to open its analytic items. From the list, open the Journal
   Item and then the related invoice, bill, expense or journal entry.
8. Switch to List or Graph without changing the search filters.
9. Use **Download XLSX** for the current pivot. **Insert in Spreadsheet**
   appears only when the installation provides a compatible writable
   spreadsheet destination.

Reloading the menu restores the product default. Adding a new configured
analytic plan automatically makes its account dimension available in the
search and pivot grouping controls.
