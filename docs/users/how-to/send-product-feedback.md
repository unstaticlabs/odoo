# Send product feedback

Use this workflow for a bug, an improvement idea, a question about behavior or
a UX problem in Odoo. Your feedback stays inside Odoo and is visible only to
you and the Feedback Maintainers who triage it.

1. Open your user menu from anywhere in Odoo.
2. Select **Send feedback**.
3. Add a short summary and describe what happened, what you expected or what
   would make the workflow clearer.
4. Choose **Bug**, **Improvement**, **Question** or **UX**, then set the
   priority.
5. Optionally attach up to ten screenshots or supporting files.
6. Decide whether to enable **Share current page context**. When enabled, Odoo
   includes only the current action, a record identifier you are allowed to
   read, the company, viewport size and exact release. It never includes the
   page URL, query strings, fragments, tokens or form contents.
7. Select **Send feedback**.

Odoo confirms the submission and returns you to the page where you started. If
the source record became unavailable, Odoo sends the feedback without that
record context and tells you it was omitted. If the running release cannot be
identified exactly, nothing is submitted; retry after an administrator repairs
the release identity.

Use **My feedback** in the same user menu to see the current stage and replies.
Open an item to follow or unfollow it, add a chatter message or attach more
detail. Submitted summary, description, category and routing metadata are
read-only; add corrections in the conversation so the history remains clear.

Feedback follows the active company. Switching company can hide feedback from
another company until that company is active again. Other employees cannot see
your feedback, its attachments or its conversation.
