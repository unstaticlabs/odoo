# Email a document

Send a file to the Documents intake address and Odoo archives it for you. Use
this for anything that arrives in your mailbox and belongs in Documents but not
on a specific invoice, expense or contact.

1. Find the address. An administrator sees it in **Settings → Documents → Email
   intake**. It is normally `documents@` followed by your email domain.
2. Send or forward the message from the address on your employee record.
   Messages from any other address are refused.
3. Attach the files. One message may carry several.
4. Write the subject you want to recognise later. It becomes the title of the
   intake, and Odoo uses **Emailed document** when the subject is empty.
5. Wait a minute or two, then open **Documents**. Each file arrives as a
   library document tagged **Email intake**, in the company on your employee
   record.

The archived document is readable by the Documents users of that company, the
same as a file attached to a contact or a project.

Odoo archives what Paperless can read. Web pages, calendar invitations, XML and
ZIP attachments, and the small images that mail clients add to signatures, stay
on the message and are not turned into documents. Send a PDF, an image or an
office file when the content matters.

An administrator can review every message the address received in **Documents →
Configuration → Emailed documents**, including the ones whose files could not
be archived.

If Settings reports that the address is unavailable, the alias has no email
domain yet. Give it one in **Settings → Technical → Email → Aliases**; setting a
domain on the company afterwards does not reach an alias that already exists.
