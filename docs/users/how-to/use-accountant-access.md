# How To Use Accountant Access Safely

Audience: accountant, CEO, administrator who grants accounting review access.

Use this guide to understand what the accountant review role can and cannot do.

## What the Accountant Reviewer Can Do

The accountant reviewer can inspect:

- imported journal items;
- accounting attachments linked to imported accounting evidence;
- report previews and exports;
- discrepancies;
- review decisions;
- external report values;
- source report catalogue;
- source report lines and expressions;
- source move workflow reviews;
- source payment workflow reviews;
- reconciliation boundary reviews;
- assets and schedules.

The accountant reviewer can also create or update draft review decisions.

## What the Accountant Reviewer Cannot Do

The accountant reviewer must not be able to:

- modify imported posted journal entries;
- delete imported accounting evidence;
- directly edit discrepancy records;
- see unrelated private technical attachments;
- see another company such as USL Media if not assigned to that company.

## Normal Review Workflow

1. Open the reconstruction summary.
2. Inspect open discrepancies.
3. Generate or preview required reports.
4. Drill down to source records.
5. Inspect supporting evidence.
6. Record decisions only where you have authority.

## If Access Looks Wrong

Ask an administrator to check:

- user company access;
- accounting read-only group;
- USL accountant reviewer group;
- whether the user is incorrectly assigned to extra companies.

Do not work around missing access by sharing private exports outside the intended review process.
